# RUWithMe demo media

[Product introduction video](ruwithme-demo.mp4) · [English subtitles](ruwithme-demo.srt)

The three minute video uses fictional academic workspaces and synthetic activities to introduce RUWithMe. It includes the user requested public credit to Halo Lab, led by Professor Yifan Hu. The repository ships the finished video, subtitles, and a preview frame; production captures, local paths, audio models, and working files are excluded.

The Pareto Frontier example refers to the completed public paper [Pareto Frontier of LLM Test-time Compute](https://optimization-online.org/2026/10/pareto-frontier-of-llm-test-time-compute-adaptive-rollouts-and-voting-under-token-budgets/). Reading and discussion examples describe a fictional workday rather than unpublished findings. The Learn example links to [Probabilistic Artificial Intelligence](https://arxiv.org/abs/2502.05244).
